# whitekiwi portfolio

An interactive portfolio journey for whitekiwi, a Node.js developer.

## Stack

- Vite + React + TypeScript
- Three.js for the future 3D world
- GSAP for scroll choreography and scene transitions
- SVG/CSS for lightweight illustration and motion prototypes

## Development

```bash
npm install
npm run dev
```

Build for production with `npm run build`.
