# Favicon concept prompts

Built-in ImageGen mode was used with `public/assets/characters/kiwi-walk-cycle.png` as an identity reference.

## A — Character close-up

```text
Use case: logo-brand
Asset type: square favicon concept for the whitekiwi developer portfolio
Input image: Image 1 is an identity reference only; use the same tall brown kiwi bird, very long golden beak, tiny dark eye, dark cocoa outline, and warm handmade character.
Primary request: create Concept A, a bold side-profile kiwi emblem optimized for browser tabs.
Subject: only the kiwi's head, upper body, long beak, and one eye; no legs; beak points right.
Style/medium: clean flat vector-like brand icon with a subtle handmade softness, editorial rather than childish.
Composition/framing: centered oversized silhouette filling a square, generous but efficient edge padding, strong readability at 16px and 32px.
Color palette: dark cocoa outline, warm chestnut body, golden ochre beak, pale warm cream background.
Constraints: one icon only; simple closed shapes; thick consistent outline; no tiny feather details; no text; no letters; no badge border; no mockup; no watermark.
Avoid: photorealism, gradients, 3D, shadows, kawaii facial features, extra props, multiple options, icon sheet.
```


## C — Egg kiwi

```text
Use case: logo-brand
Asset type: square favicon concept for the whitekiwi developer portfolio
Input image: Image 1 is an identity reference only; translate its long beak, small eye, brown kiwi personality, and dark outline into a new compact symbol.
Primary request: create Concept C, a Milk Glass egg that subtly transforms into a kiwi bird.
Subject: a single upright off-white egg silhouette; from the right side emerges the recognizable long golden kiwi beak, with one tiny cocoa eye on the egg; one restrained chestnut crescent suggests the brown bird beneath the shell.
Style/medium: minimal flat vector-like icon, refined and surprising, connected to the portfolio's egg-to-kiwi prologue.
Composition/framing: centered oversized symbol on a warm chestnut square; clean silhouette with equal visual weight in all directions, readable at 16px.
Color palette: warm chestnut background, milk glass off-white egg, dark cocoa details, golden ochre beak.
Constraints: one icon only; maximum four flat colors; thick shapes; no cracks finer than 2px-equivalent; no legs; no text; no letters; no mockup; no watermark.
Avoid: realistic glass, transparency effects, gradients, shadows, hatching, many shell fragments, multiple options.
```

## D — Three shape

```text
Use case: logo-brand
Asset type: square favicon concept for the whitekiwi developer portfolio
Input image: Image 1 is an identity reference only; preserve the unmistakable long-beaked kiwi silhouette and warm brown/gold identity.
Primary request: create Concept D, an ultra-minimal abstract kiwi mark made from only three shapes.

```

## First-pass review

- A and D retain the strongest kiwi recognition at 16 px.
- C best connects the icon to the egg-to-kiwi prologue, but its beak needs a larger small-size master.
- B has strong contrast but reads less like the established brown kiwi character.
